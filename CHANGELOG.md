# Changelog

All notable changes to Codex MenuBar KDE are documented here.

## 0.2.0

- Add 7-day local usage history with a compact chart and clear action.
- Add configurable low-quota Plasma desktop notifications.
- Display additional Codex rate-limit buckets reported by `rateLimitsByLimitId`.
- Improve compact panel spacing and vertical alignment.
- Make the popup scrollable for smaller displays.
- Preserve existing quota windows across sparse live updates.
- Add Arch/AUR packaging assets.
- Add tagged GitHub release automation with version consistency checks.
- Add history-store tests and QML linting to CI.

## 0.1.1

- Add the KDE/Plasma blue dual-arc logo.
- Restore the panel icon alongside quota values.
- Improve quota rendering and diagnostics.
- Accept nullable Codex rate-limit window metadata.
- Fix QML backend binding for compact and full representations.

## 0.1.0

- Initial Plasma 6 widget.
- Persistent Codex app-server integration.
- Five-hour and weekly quota display.
- Configurable panel representation and fallback refresh.
